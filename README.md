# Droidex

Collection tracker for **Star Wars: Droid Tycoon** in Fortnite.

Repo: [Falcorfrenzie516/FortniteDroidTycoon](https://github.com/Falcorfrenzie516/FortniteDroidTycoon)

After Pages is on, the site is:

**https://falcorfrenzie516.github.io/FortniteDroidTycoon/**

Tracks regular droids (7 variants + Flawless), the 17 fusion recipes, event iconics, and workshop cosmetics. Progress is saved in the browser (`localStorage`) on that device.

## What’s in this repo

```
index.html      tracker
manifest.json   Add to Home Screen metadata
README.md
.gitignore
```

No build step.

## Turn on GitHub Pages

1. Open the repo → **Settings** → **Pages**
2. **Source**: Deploy from a branch
3. Branch: `main` (or `master`), folder: `/ (root)`
4. Save
5. Wait a minute, then open the URL above

On iPhone Safari: open that URL → Share → **Add to Home Screen**.

## Notes

- Checks stay on the device/browser that made them.
- Fusion droids are the 17 named recipes. Three copies of the same droid fuse to the next variant.
- Higher variants cover lower rebirth requirements.
